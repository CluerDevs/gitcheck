GitCheck Privacy Policy

Last updated: October 20, 2026

GitCheck is a browser extension that scores GitHub repositories and lists trending ones. It does not collect, store, sell or share your personal data.

What GitCheck does not do

  • No accounts, sign-in, analytics, tracking, advertising or telemetry.
  • No data is sent to the developer or any server we operate.
  • No remote code is loaded. All code ships inside the extension.

Data stored on your device

GitCheck uses your browser's local extension storage (chrome.storage.local) for:

  • Your chosen theme.
  • An optional GitHub personal access token, only if you enter one in Settings. It is used solely to raise GitHub's API rate limit.
  • A 30-minute cache of trending results, to avoid repeat requests.

This data never leaves your browser except as described below. Removing the extension deletes it.

Network requests

GitCheck sends requests to the public GitHub API (https://api.github.com) to read public repository information (such as stars, license, releases, contributors and file names) and search results. If you saved a token, it is sent to GitHub in the Authorization header of those requests. These requests are subject to GitHub's privacy statement. The repository you are viewing is read from the page address, and the page contents are not collected.

Permissions

  • storage: theme, optional token and cache, as above.
  • activeTab: read the current tab's address to pre-fill the repo to check.
  • clipboardWrite: the "Copy" buttons.
  • api.github.com access and a content script on github.com: show results on repository pages and fetch public data.

Children

GitCheck is a developer tool and is not directed at children.
